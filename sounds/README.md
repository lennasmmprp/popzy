# Sons Popzy (optionnel)

Par défaut, tous les sons sont **générés en direct** par `sound.js` (Web Audio) : ce dossier peut rester vide.

Pour remplacer un son synthétisé par un vrai enregistrement :
1. Dépose le fichier ici avec **exactement** un des noms ci-dessous (mp3, ogg ou wav).
2. Ajoute son nom dans `sounds.json`, par exemple : `["crunch.mp3", "bubble-pop.mp3"]`.

| Fichier | Moment | Quoi chercher (Freesound, Pixabay, Zapsplat) |
|---|---|---|
| `capsule-crack` | la capsule se fissure | "plastic crack", "shell crack short" |
| `capsule-pop` | ouverture de la capsule | "cork pop soft", "pop open" |
| `sweet-breath` | souffle après l'ouverture | "air whoosh soft", "breath airy" |
| `shimmer` | le chewing-gum apparaît | "sparkle shimmer", "magic twinkle short" |
| `crunch` | étape 1, premier croc | "candy crunch", "bite hard candy", "ASMR crunch" |
| `crunch-squish` | étape 2 | "chewing gum chew", "bite crunchy wet" |
| `stretch` | étape 3, étirement slime | "slime stretch", "rubber stretch" |
| `squish` | squish moelleux (étapes 2 et 3) | "slime squish ASMR", "squishy" |
| `bubble-inflate` | étape 4, la bulle gonfle | "balloon inflate short", "bubble blow" |
| `bubble-pop` | étape 4, la bulle éclate | "bubble gum pop", "bubble pop" |

Garde des sons courts (0,2 à 1 s), sans silence au début, et vérifie la licence (CC0 de préférence).
